# Deterministic Benchmark Dataset

Each document number `i` in `0..N` is generated from a recorded unsigned
64-bit seed `s`. Arithmetic is wrapping unsigned arithmetic.

```text
x0 = s XOR i
x1 = x0 XOR (x0 << 13)
x2 = x1 XOR (x1 >> 7)
x3 = x2 XOR (x2 << 17)
```

Create a `records` document with these fields:

- `sequence`: `i` as an integer;
- `group`: `"g" + (x3 mod 1000)`;
- `region`: one of `north`, `south`, `east`, `west` by `x3 mod 4`;
- `active`: true when `x3 mod 2` is zero;
- `score`: `(x3 mod 10000)` as an integer;
- `profile.rank`: `(x3 mod 100000)` as an integer; and
- `tags`: `common` plus `"t" + (x3 mod 100)`.

Generate exactly 10,000, 100,000, 500,000, or 1,000,000 documents. Record `N`,
`s`, insertion order, batch size, and the resulting data/index byte counts.
The `_id` is generated by NovaDB and must be retained when replaying an exported
dataset. This specification avoids committing large generated files while
making every logical field distribution reproducible.
